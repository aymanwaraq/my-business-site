📱 Bilingual Booking System

Client Problem
Businesses serving English and Arabic speaking customers need a booking platform that supports both languages, RTL layout, and integrates with WhatsApp for automated reminders.

Solution
A full-stack booking platform was built with Python and Streamlit, featuring bilingual interfaces, RTL CSS support, and Twilio API integration for WhatsApp notifications. The system dynamically switches between English and Arabic based on user preference.

Results
✔ Seamless bilingual user experience
✔ RTL layout correctly rendered for Arabic users
✔ Automated WhatsApp reminders reduce no-shows
✔ Scalable architecture for multi-region deployment

Technologies
Python · Streamlit · Twilio API · HTML/CSS · Flask
