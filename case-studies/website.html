🌐 Bilingual Business Website

Client Problem
Businesses need a modern, responsive website that supports both English and Arabic, with RTL layout, smooth animations, and a professional brand presence for international audiences.

Solution
A fully responsive bilingual website was developed using HTML, CSS, and JavaScript. Features include RTL support for Arabic, glass-morphism design, smooth scroll animations, and custom domain deployment via GitHub Pages.

Results
✔ Modern, professional brand presence
✔ Fully responsive across all devices (mobile, tablet, desktop)
✔ Bilingual support with automatic RTL/LTR switching
✔ Smooth animations and interactive UI components

Technologies
HTML5 · CSS3 · JavaScript · GitHub Pages · Custom domain (btsapp.net)
